# Components

For details on what components are, please see the component section of the [repository file structure document](RepositoryFileStructure.md).

COHO's components are all generated from [ROBOT templates](http://robot.obolibrary.org/template), the tables in `src/templates`. They are listed under `components` in `owlmake.yaml`:

```
components:
  products:
  - filename: GWAS.owl
    use_template: true
    template_options: '--prefix "COHO: http://www.ebi.ac.uk/coho/COHO_" ...'
    templates:
    - GWAS.csv
```

`template_options` gives the prefixes the templates' CURIEs are written with (`COHO:`, `dbpedia:`, `RO:`, `oio:`).

## Editing a component

Never edit the files in `src/ontology/components`: they are rebuilt from the templates. Instead:

1. Edit the template in `src/templates` (for example `src/templates/GWAS.csv`)
2. Rebuild the components:
   ```
   om make recreate-components
   ```
3. Run the [quality control checks](QualityControl.md): `om make test IMP=false`
4. Commit the template and the rebuilt component together

## Adding a component

1. Create the template, `src/templates/your-component-name.tsv` (or `.csv`)
2. Add the component to the `components` list in `owlmake.yaml`, as above
3. Bring the repository into step with `owlmake.yaml`:
   ```
   om update-repo
   ```
   This adds the component to the imports of the edit file (`src/ontology/coho-edit.owl`), tells the XML catalog (`src/ontology/catalog-v001.xml`) where its IRI is to be found, so that Protégé and the build can load it, and creates a placeholder `src/ontology/components/your-component-name.owl`.
4. Build it: `om make recreate-components`

Removing a component is the same in reverse: take it out of `owlmake.yaml`, run `om update-repo`, and delete its file.

A component can also be derived from SSSOM mappings (`use_mappings: true` with a list of `mappings`) or fetched from a remote resource (`source: https://example.org/component-source.owl`). One that is generated by a process of its own is described as a target, see [Build configuration](BuildConfiguration.md#building-something-in-a-way-of-your-own).
